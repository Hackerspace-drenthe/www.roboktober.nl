# Release Notes - 2026-08-10

Deze release note legt operationele fixes en validaties vast die op productie zijn uitgevoerd.

## Highlights

### 1. SMTP delivery gefixt en gevalideerd
- Productie mailconfig is gecorrigeerd voor TransIP SMTP authenticatie.
- End-to-end testmail is succesvol verzonden en ontvangen.
- Belangrijk leermoment: `MAIL_SCHEME=tls` was in deze setup ongeldig; met `MAIL_SCHEME=null` en poort 587 werkte verzending correct.

### 2. Productie data cleanup uitgevoerd
- Dummy testteams en gekoppelde teamdata zijn opgeschoond na dry-run en expliciete bevestiging.
- Competitie-tabellen met testdata zijn geleegd.
- Uitvoering is gevalideerd met before/after aantallen.

### 3. Productie DB backup gemaakt
- Voor operationele veiligheid is een timestamped database backup (`.sql.gz`) aangemaakt in `storage/backups`.
- Bestandsgrootte en succesvolle exitcode zijn bevestigd.

### 4. Lokale teststatus volledig groen
- Backend: `php artisan test` en `composer test` slagen lokaal.
- Frontend: `npm run test`, `npm run test:unit` en `npm run test:e2e` slagen lokaal.
- Productiehost draait geen volledige dev test-tooling; dit is nu expliciet gedocumenteerd als verwacht operationeel model.

### 5. KiCad updates gepubliceerd met duidelijke ontwikkelstatus
- KiCad-bestanden mogen gepubliceerd worden voor samenwerking en zichtbaarheid.
- Deze updates zijn nog in development stage en nog niet werkend.
- Ze zijn daarom expliciet niet vrijgegeven als productie- of releaseontwerp.

### 6. Fallback-besluit vastgelegd voor PCB planning
- Er is een officieel fallback-scenario vastgelegd: als de PCB niet op tijd klaar is, wordt overgeschakeld op handmatige wiring en solderen.
- Go/no-go beslismoment: 1 maand voor het event.
- Tot vrijgave blijven de KiCad updates publiceerbaar voor review, maar niet inzetbaar als productieontwerp.

## Operationele impact

- Mailnotificaties zijn weer betrouwbaar voor account/registratieflows.
- Competitiedata staat schoon voor het vullen met echte eventdata.
- Deploy- en API-documentatie zijn bijgewerkt met concrete runbooks voor mailcheck, backup en veilige cleanup.

## Changelog referenties

- SMTP productiefix en verificatie (TransIP)
- Productie cleanup teams/competitie
- Productie backup run
- Lokale volledige testverificatie
- KiCad updates gepubliceerd als work-in-progress (niet werkend)
- PCB fallback protocol vastgelegd (handmatige wiring bij vertraging)
