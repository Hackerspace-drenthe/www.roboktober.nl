Deze release note legt de geverifieerde teststatus vast.

## Highlights

### 1. Frontend tests opnieuw geverifieerd
- Vitest unit suite slaagt.
- Playwright e2e smoke suite slaagt na installatie van de benodigde Chromium-browsers.
- De frontend testworkflow is daarmee weer reproduceerbaar in deze workspace.

### 2. Backend testuitvoering geblokkeerd door workspace-tooling
- Backend tests konden niet worden uitgevoerd in deze omgeving, omdat `php` en `composer` niet beschikbaar zijn.
- Ook een niet-interactieve `sudo`-installatie is hier niet mogelijk.
- De docs zijn bijgewerkt om dit als actuele blokkade vast te leggen.

## Technische samenvatting
- Frontend dependency-installatie is uitgevoerd met `npm ci`.
- Playwright Chromium is geïnstalleerd met `npx playwright install chromium`.
- De frontend e2e smoke suite draaide daarna succesvol.
