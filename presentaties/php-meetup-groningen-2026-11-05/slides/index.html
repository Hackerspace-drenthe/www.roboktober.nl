Op de robot · wat gebeurt er als het signaal binnenkomt?

  1. 📶 Signaal binnenESP32-C3 ontvangt gas 2000
  2. 🧠 ESP stuurt aanPWM 92 % → DRV8833
  3. 🔋 Accu levert stroom1S LiPo → DRV8833
  4. ⚡ DRV8833 schakeltaccu → motoren, ≈ 3,4 V

[3.5.1 · 2 min] Klik 5×. Echte KiCad-render van PCB v4 (onderkant, dus gespiegeld): ESP32-C3-headers, rode DRV8833-module, accu-connector, M1/M2-connectoren. 1) ESP-NOW-pakket komt binnen (gas 2000, sturen 1500). 2) ESP rekent 236 uit (niet 255: RC_MAX = 2040) en zet PWM op 2 pinnen per motor (GPIO6/10, 5 kHz, 236/256 ≈ 92 %). 3) De ESP levert geen stroom voor de motoren — dat doet de accu via de DRV8833. 4) H-brug schakelt de accu 5000×/s op de motor → gemiddeld ≈ 3,4 V. 5) Rechtdoor. Alle lijnen zijn de échte koperbanen uit KiCad (pads/tracks omgerekend naar de render, ±1 px). Blauw fel = GPIO6 + GPIO10 (PWM), blauw dim = GPIO7 + GPIO9 (staan op 0). Rood = accu → aan/uit-schakelaar → helemaal over de rand → VM van de DRV8833. Geel = motoruitgangen M1A/M1B en M2A/M2B naar de JST-connectoren. Failsafe: na 500 ms geen pakket → alles 0.

0−255−40+40+255

Deadband (RC_DEADBAND 40): een joystick staat in rust nooit precies op 0 — er is altijd wat ruis en speling. Alles tussen −40 en +40 wordt hard 0, anders kruipt de robot langzaam weg terwijl je niks doet.

Wat gebeurt er als je de joystick naar voren duwt?

  1. Antweight: 150 g, ~€25, laagdrempelig.
  2. Elektronica heeft vaste afspraken en controles, en een 3D-model kan gewoon code zijn.
  3. De controller is software: geen app nodig, wel invoer controleren en weten wie je bestuurt.
  4. Met een goed plan + AI + tests bouwt één developer dit in 3 maanden.
